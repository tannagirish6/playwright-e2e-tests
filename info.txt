PlayWright Architecture!

PlayWright - happens via webSocket protocol!

Test Runner -> Client API ( PlayWright- core ) -> Communication Layer ( Web Socket ) -> Browser Server -> Browsers ( chrome, etc )

Playwright Installation

npm init playwright@latest

npx playwight --help ( to check and confirm )

npx playwright test ( runs the spec.ts files from the 'tests' folder, auto runs in headless mode that is no browser  )

npx playwright test --headed ( runs with opening browser )

npx playwright show-report ( by default shows the test report, check playwright.config.ts ' reporter: 'html' '

Naming Conventions

Files/Folders  ( kebab-case ) => page-ojects/, file-helper.js
Page and Spec Files ( dot-separated ) => nopcommerce.home.page.ts
Class Names   ( Pascal Case ) => LoginPage
Variables    camelCase
Constants    UPPER_SNAKE_CASE => BASE_URL
